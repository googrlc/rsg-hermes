# Hermes Tool Map

Operator reference for what the conversational agent can run today. The **Live
runtime tools** table below is generated from the same source as the Command
Center skills API (`GET /api/command-center/skills`) — regenerate it whenever
tools are added or removed:

```bash
source .venv/bin/activate
python scripts/gen_tool_map.py
```

Use `--check` in CI to fail when the doc drifts from the live catalog.

Operator roles, write tiers, and approval tokens:
[`identity-permissions-matrix.md`](identity-permissions-matrix.md).

## Domain playbooks

Domain skills (`.claude/skills/*/SKILL.md`) are listed by the same API under
`domain_skills` but are not auto-synced into this doc yet. Call
`GET /api/command-center/skills` or use the `list_skills` agent tool.
